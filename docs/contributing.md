# Contribuir

1. Revisa las [normas de MC-Andes](https://github.com/MC-Andes/standards).
2. Abre un issue de bug, funcionalidad o pregunta.
3. Crea una rama corta desde `main`.
4. Actualiza páginas o posts y ejecuta `mkdocs build --strict`.
5. Abre un Pull Request con objetivo, validación y checklist de calidad.

## Publicar en el blog

Los posts breves usan fecha y título, y las secciones **Contexto**, **Cambio**,
**Impacto** y **Próximo paso**. Incluye enlaces a las decisiones o artefactos
relacionados. La meta editorial es un avance semanal y un digest mensual.
