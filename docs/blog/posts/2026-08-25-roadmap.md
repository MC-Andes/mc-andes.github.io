# Roadmap: de las plantillas al primer proyecto reproducible

## Contexto

Una estructura solo es útil cuando guía trabajo real. La primera etapa debe
probar que las normas, la CI y la documentación funcionan juntas.

## Cambio

El roadmap se divide en fundación, visibilidad y operación. Después de publicar
los cinco repositorios base, crearemos un piloto de elementos finitos, un backlog
técnico corto y una primera release `v0.1.0`.

## Impacto

El piloto mostrará qué controles aportan valor y cuáles necesitan simplificarse.
Las decisiones quedarán enlazadas desde issues y Pull Requests.

## Próximo paso

Seleccionar el alcance del repositorio piloto, abrir entre tres y cinco issues y
definir un ejemplo verificable pequeño. Revisa los
[proyectos disponibles](../../projects.md).
