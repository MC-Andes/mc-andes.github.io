# Publicaciones

Esta sección enlazará artículos, software citable, datasets y material técnico
producido por MC-Andes.

## Cómo añadir una publicación

Abre un Pull Request con referencia completa, DOI o enlace persistente,
repositorio relacionado y licencia de los artefactos. Cuando exista software
asociado, actualiza también su `CITATION.cff`.
