- **FEniCSx/DOLFINx para mecánica computacional**

    ---

    **Nivel:** fundamentos a avanzado<br>
    **Idioma:** español<br>
    **Estado:** curso continuo · v0.1.1 estable<br>
    **Entorno:** FEniCSx 0.11 · Python 3.12 · MPI/PETSc

    Comienza con forma débil y un laboratorio de Poisson guiado en ocho pasos;
    continúa con objetos de DOLFINx, mallas y espacios; después permite elegir
    rutas de calor, sólidos, fluidos y multifísica. Diagramas originales conectan
    la matemática, el código, la malla, los grados de libertad y la convergencia.

    **Cómo se aprende:** predicción → script `.py` → punto de control → JSON de
    verificación → visualización. No requiere cuadernos Jupyter.
